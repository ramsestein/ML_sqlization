CONSULTAS PARA DATANEX (AWS Athena) - generadas por fnxsql
==========================================================

Cada fichero .txt es UNA consulta autocontenida: se pega en Athena, se ejecuta y se descarga su resultado como CSV.
No dependen unas de otras. Usan las tablas del esquema datascope_gestor_prod (episodes, rc, labs, demographics), las mismas
que FakeNex.

Los pacientes se eligen dentro de cada consulta con un hash de patient_ref entre los que tienen algún ingreso HOSP o
HOSP_IQ: todas las consultas usan los mismos 10 pacientes.

Consultas
---------
  00_variables_10_pacientes.txt
      Las 37 variables de los ingresos de 10 pacientes al azar.
  01_inferencia_logistica.txt
      Probabilidad del modelo logistica para esos ingresos (18 KB).
  02_inferencia_arbol.txt
      Probabilidad del modelo arbol para esos ingresos (10 KB).
  03_inferencia_random_forest.txt
      Probabilidad del modelo random_forest para esos ingresos (59 KB).
  04_inferencia_boosting.txt
      Probabilidad del modelo boosting para esos ingresos (56 KB).
  05_inferencia_red_pequena.txt
      Probabilidad del modelo red_pequena para esos ingresos (14 KB).
  06_inferencia_red_mediana.txt
      Probabilidad del modelo red_mediana para esos ingresos (20 KB).
  07_inferencia_red_grande.txt
      Probabilidad del modelo red_grande para esos ingresos (84 KB).
  08_inferencia_xgboost.txt
      Probabilidad del modelo xgboost para esos ingresos (63 KB).

Resultados
----------
- Inferencia: una fila por ingreso (patient_ref, episode_ref, ingreso, momento, probabilidad). Los modelos son los de
  práctica de fnxsql (entrenados con datos sintéticos de FakeNex): es una prueba de funcionamiento, no de rendimiento.
- Variables: una fila por ingreso con las variables v000, v001... (la cabecera de la consulta dice cuál es cada una).

Para comprobarlo después (en local, con fnxsql): guardar cada CSV con el mismo nombre que su consulta (.txt -> .csv) en
una carpeta y ejecutar
  python -m fnxsql datanex comprobar --csv <carpeta>
que compara cada inferencia con el modelo evaluado en local sobre el CSV de variables (comprobacion.csv).
